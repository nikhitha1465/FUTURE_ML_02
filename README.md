# FUTURE_ML_02
# Support Ticket Classification using Machine Learning

## 📌 Project Overview

This project uses Machine Learning and Natural Language Processing (NLP) to automatically classify customer support tickets based on their category and priority. The model helps reduce manual effort by predicting the appropriate category and urgency level for incoming customer queries.

## 🚀 Features

- Predicts ticket category
- Predicts ticket priority
- Text preprocessing using NLP
- User-friendly Streamlit web application
- Trained Machine Learning models for classification

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

```bash

```

The dataset contains customer support tickets with their corresponding categories and priority labels used for training and evaluation.
